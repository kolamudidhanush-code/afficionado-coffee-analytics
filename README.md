# ☕ Afficionado Coffee Analytics

### Interactive Sales Analytics Dashboard for Coffee Retail

An interactive analytics dashboard designed to explore coffee sales performance, product-level revenue contribution, category trends, and store-level performance at Afficionado Coffee Roasters.

🔗 **Live Dashboard:** [Explore the Interactive App](https://afficionado-coffee-analytics-3a649c5syung4o9f59grke.streamlit.app/)

💻 **GitHub Repository:** [View Source Code](https://github.com/kolamudidhanush-code/afficionado-coffee-analytics)

---

## 📌 Project Overview

The Afficionado Coffee Analytics project uses data analytics and interactive visualization to help explore sales performance and identify useful business insights.

The dashboard brings key sales metrics and product comparisons together in one interface, making it easier to examine revenue contribution, product performance, category trends, and store-level results.

## 🎯 Project Objectives

- Analyze coffee sales and revenue patterns.
- Compare product and category performance.
- Explore store-level sales performance.
- Identify products contributing to overall revenue.
- Present findings through an interactive dashboard.

## 📊 Dashboard Features

- **Key Performance Indicators:** Overview of important sales metrics.
- **Product Performance:** Compare products and their revenue contribution.
- **Category Analysis:** Explore sales patterns across categories.
- **Store Performance:** Examine performance across store locations.
- **Revenue Contribution:** Understand how individual products contribute to revenue.
- **Interactive Visualizations:** Explore the available charts and tables.

## 🛠️ Technologies Used

- **Python** — data processing and application logic
- **Pandas** — data manipulation and analysis
- **Streamlit** — interactive web dashboard
- **Data Visualization** — presenting sales metrics and comparisons

## 🚀 Run the Project Locally

### 1. Clone the repository

```bash
git clone https://github.com/kolamudidhanush-code/afficionado-coffee-analytics.git
cd afficionado-coffee-analytics
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Launch the dashboard

```bash
streamlit run app.py
```

Open the local URL displayed in your terminal to explore the dashboard.

## 💡 Business Value

The dashboard provides a consolidated view of sales performance that can help users investigate:

- Which products contribute most to revenue.
- How product categories compare.
- How sales performance differs across stores.
- Where further product or sales analysis may be useful.

These are analytical questions the dashboard supports; conclusions should be drawn from the actual dataset and results.
